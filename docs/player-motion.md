# Player motion and verification

## Renderer boundaries

Cadence already has CSS motion tokens and overlay presence, a measured sidebar indicator, and an upstream Braccato lyrics renderer. The player pass uses those plus the native Web Animations API. It adds no animation dependency and does not change the audio engine, queue ordering, autoplay, or lyric parsing/timestamps.

- **Track changes.** The bar, Mini Player, and Now Playing use `usePlaybackPresentation`. Successful decodes are remembered by immutable artwork URL and concurrent consumers share a pending decode. Each component keeps at most two cover/text/tint layers. The last good cover stays visible until the next decode settles; the latest target wins under rapid skips. Metadata does not wait indefinitely for artwork. The 320 ms cover dissolve uses a slight settling scale and crossfades a sampled colour wash; blurred-artwork profiles keep a static blur, not an animated blur radius. The existing fluid mode still owns its shader transition.
- **Shared layout.** `PlayerLayoutMotion` reads viewport geometry before React replaces the layout, then animates toward the new geometry for 380 ms. Only artwork and metadata use inert visual copies; the moving transport and the untransformed seek input are real controls. Mini artwork opens windowed Now Playing; Restore Full Player returns to the previous route. The Tauri bridge restores window size before expansion and shrinks after collapse. A reversal starts at the currently displayed position; a resize cancels stale geometry.
- **Lyrics.** Built-in themes use Braccato's 240 ms compensated scroll with a restrained line settle. A large seek lands at the actual target line first and uses a brief visual settle, not a scroll through all the skipped lines. Hidden lyrics don't keep a local media frame loop alive. Both reduced-motion preferences skip decorative travel while preserving timed highlighting. User-authored custom-theme scroll settings still apply in standard motion mode.
- **Navigation and queue.** Browse exits are inert and retained for at most 120 ms; lyrics and settings are not retained as outgoing live views. Sidebar indicator motion is transform-based. Queue layout motion is keyed by occurrence ID, samples only the viewport plus a one-row edge buffer, and caps motion at 24 live rows and eight temporary exit copies. Removed occurrences leave the authoritative queue immediately.

## Checks

With the generated audio fixtures (`python3 tests/fixtures/generate-audio.py`), run `npm run typecheck`, `npm run build`, `npm run test:animation`, `npm run test:now-playing`, `npm run test:lyrics-ui`, and `npm run test:audio`. Run the offline unit suite with `npm test -- --exclude tests/unit/_matasaburo_full.test.ts` (the excluded suite requires a local provider key). The motion audit captures real intermediate and settled Chromium frames under `.artifacts/animation-audit/`; the separate Now Playing suite covers layouts, profiles, and background modes under `.artifacts/now-playing-layout/`.

On a desktop build, check Mini → artwork → Now Playing and Mini → Restore on a resized window, including quick reversals and while seeking or skipping. Repeat with hidden artwork, a narrow window, and both reduced-motion preferences. Chromium tests exercise native resize ordering with a mocked bridge; actual OS window-manager behavior and Intel UHD hardware performance still need a native smoke test.
